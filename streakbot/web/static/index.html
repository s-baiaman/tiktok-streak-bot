    Where do I find it?
    1. Log in to tiktok.com in a desktop browser.
    2. Open developer tools (F12) → Application (Chrome) or Storage (Firefox) → Cookies → https://www.tiktok.com.
    3. Copy the value of sessionid. Pasting the whole cookie line also works.

    Don't log out of TikTok in that browser afterwards. Logging out kills the cookie.
